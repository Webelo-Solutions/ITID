# ITID Taxonomy Export

A full export of the SCOUT-v2 ITID (Incident Type IDentifier) taxonomy: all tiers (1-5), full 11-section Definition Document content for every active Tier-5 leaf, and each leaf's PICERL-methodology incident-response playbook (steps included).

Generated from the live SCOUT-v2 database. See `itid-taxonomy-export.json`'s own `summary` field for node/playbook/step counts at time of export.

This repository is intentionally kept separate from the main SCOUT-v2 application repository.
